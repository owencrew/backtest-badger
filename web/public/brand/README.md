# Mascot assets

- `badger-mascot.webp` is the primary homepage mascot: the owner's original
  black-and-white badger digging through earth with financial candlesticks.
  Approved source: `~/Downloads/backtest-badger-mascot.png`, supplied 27 October
  2026. The original is retained byte-for-byte at
  `design-assets/badger-mascot-original.png` from the repository root.
- Source: 1254 × 1254 RGB PNG, no alpha, 1,794,240 bytes. SHA-256:
  `329489b45da2249465a9bcf99fa57849aec168874f3968b5f9b35494aa2d2f47`.
  Delivered lossless WebP: 948,680 bytes (47.1% smaller). Decoded RGB pixels match
  exactly. No generation, resizing, background removal or composition edit.
- CSS multiply blending integrates the white background with the warm-sand panel.
  Contain sizing keeps claws and soil candlesticks intact; mobile panels are taller
  to retain detail. The build references only the checked-in WebP.
- `badger-mark.svg` remains the simplified geometric head used for navigation,
  favicon and badge. It was not regenerated.
- The former `badger-engraving.png` is no longer deployed. Its separate historical
  source `design-assets/badger-reference.png` remains unchanged. Owner confirmation
  of originality applies to the new mascot, not to unrelated historical assets.
