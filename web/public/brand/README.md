# Mascot assets

- `badger-engraving.png` is a byte-for-byte copy of the owner-provided
  `design-assets/badger-reference.png`. It is not a newly drawn illustration.
  The homepage uses CSS multiply blending on a warm-sand panel to remove the
  visual white rectangle without altering the original image or pretending to
  create an alpha cutout.
- `badger-mark.svg` is a newly constructed, simplified geometric head emblem,
  informed by the reference's black-and-white facial stripes. It is not a vector
  trace of the engraving. It has a transparent background and is reused for
  navigation, the favicon and the animation-ready badge.

No full transparent woodcut, traced vector engraving or AI-generated mascot is
claimed. The original is preserved. Confirm artwork rights and attribution
requirements before a future public launch; third-party asset rights are not
automatically covered by the repository's code license.
