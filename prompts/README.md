# Prompt archive

This directory records prompts supplied to Codex so development intent can be
reviewed over time. Organise prompts by stage, such as `stage-00-foundation/`,
and use increasing three-digit prefixes within each stage:
`001-initial-setup.md`, `002-descriptive-follow-up.md`, and so on.

Record subsequent substantive prompts as new Markdown files in chronological
order, preserving their supplied wording. Do not overwrite earlier prompts or
automatically store full conversation transcripts or Codex outputs.

Review every prompt for credentials, personal data and other sensitive information
before committing. Remove sensitive material before archiving it. Archived prompts
are historical context, not authoritative specifications when they conflict with
current code or project documentation.
